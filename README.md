### What I'm working on

These days I'm working on [simplecompress](https://github.com/shiciro/simplecompress) (UltimateCompress), a Python tool that batch-compresses images and videos. It converts images and animated GIFs to WebP, re-encodes video with FFmpeg, and picks up GPU acceleration automatically (NVENC, QSV, AMF, VAAPI) with a CPU fallback. It also handles backups, file conflicts, and logging, and shows live multi-bar progress with `rich`. Animated GIFs usually come out 70% to 85% smaller.

For my undergraduate thesis I built [Web-Output-Skripsi](https://github.com/shiciro/Web-Output-Skripsi), a decision support system that scores alternatives per judge with the SMART method, then combines the rankings with Borda count. It runs entirely in the browser with no build step.

A few other things I've spent time on:

- Mobile apps. Flutter projects including a [quiz widget](https://github.com/shiciro/flutterquizwidget), a [contact app](https://github.com/shiciro/contactflutter), and my [programming course final](https://github.com/shiciro/PEMRO-UAS-FLUTTER).
- Web development. PHP projects like a [web quiz](https://github.com/shiciro/quizPemproWeb) and my [web programming final](https://github.com/shiciro/PWEB-UAS).
- Data and OOP. A [statistics notebook](https://github.com/shiciro/statistika) in Jupyter and an [object-oriented Python project](https://github.com/shiciro/PBO-TUGAS-AKHIR).
